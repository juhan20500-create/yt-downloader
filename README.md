# 동영상 다운로더 (Video Downloader)

유튜브·틱톡 영상을 **최고화질로 받고**, 원하면 **구간만 잘라 저장**하는 프로그램입니다.
완전 로컬로 동작합니다.

- 유튜브 shorts·롱폼, 틱톡 지원 (최고화질 자동 선택)
- 여러 URL 한 번에 · 실시간 진행률 · 중복 방지
- **구간 편집**: 영상을 불러와 타임라인을 마우스로 끌어 원하는 부분만 정밀하게 저장
- 맥 / 윈도우 모두 동작 (파이썬 설치 불필요)

---

## 설치 (파이썬 불필요)

[**Releases 페이지**](../../releases/latest) 에서 자기 OS 파일을 받으세요.

| 운영체제 | 파일 |
|---|---|
| 윈도우 | `yt-downloader-windows.exe` |
| 맥 | `yt-downloader-macos` |

### 실행
- **윈도우**: exe 더블클릭 → "Windows의 PC 보호" 경고 시 → **추가 정보 → 실행**
- **맥**: 받은 파일 **우클릭 → 열기** → "확인되지 않은 개발자" 경고 → **열기**

실행하면 브라우저가 자동으로 열립니다. (`http://127.0.0.1:5055`)

> **첫 실행은 조금 느립니다.** 유튜브 조회 도구(yt-dlp)를 처음 한 번 자동으로 내려받습니다.
> (영상 병합에 필요한 ffmpeg는 프로그램에 이미 포함돼 있습니다.)
> 첫 실행에는 인터넷 연결이 필요합니다.

## 사용법

**전체 다운로드**
1. URL 붙여넣기 (여러 개면 한 줄에 하나씩) → **다운로드**
2. `Downloads/다운받은 영상` 폴더에 저장됩니다

**구간 편집** (우측 상단 `✂️ 구간 편집`)
1. URL 넣고 **불러오기** → 영상이 뜸
2. 타임라인의 보라 손잡이를 마우스로 끌어 구간 지정 (또는 재생하며 "재생위치를" 버튼)
3. **이 구간 저장** → 그 부분만 정밀하게 잘려 저장

## 선택 설정 (환경변수)

| 변수 | 설명 |
|---|---|
| `YTDLP_COOKIES_BROWSER` | 로그인 상태로 받고 싶을 때 브라우저 지정 (예: `chrome`). 틱톡이 막힐 때 도움 |
| `YTDL_PORT` | 실행 포트 변경 (기본 5055) |

## 참고
- 틱톡은 접속 제한이 걸릴 때가 있어 자동으로 여러 번 재시도합니다. 그래도 실패하면 잠시 후 다시 시도하세요.
- 재생·저장되는 화질은 원본이 제공하는 최고화질입니다. 원본이 저화질이면 그 이상은 나오지 않습니다.
